# CSS Grid: `grid-column-start`

Ba ví dụ tách riêng minh họa các giá trị `auto`, `span 2` và đường kẻ cột `2`.

## Chạy và chụp ảnh

Mở `index.html` trong trình duyệt. So sánh item đầu tiên ở mỗi lưới; ví dụ C đánh dấu năm đường kẻ của lưới bốn cột. Chụp màn hình các ví dụ để nộp bài.

## Ghi chú

`auto` dùng auto-placement; `span 2` làm item trải qua hai track; số nguyên `2` chỉ định đường kẻ bắt đầu tại vị trí số 2.
